## 5. Continuous Integration (CI) Enforcement

Every commit and pull request touching `eval/` or `Backend/` triggers the automated GitHub Actions quality gate ([.github/workflows/eval-ci.yml](../.github/workflows/eval-ci.yml)):
1. **Schema Check**: Validates that all meeting JSON files strictly adhere to `eval/schema.py`.
2. **Judge Calibration**: Verifies that the LLM Judge maintains $\ge 80\%$ agreement with human ground truth.
3. **Threshold Gate**: Enforces that:
   - Action Item F1 must be $\ge 75.0\%$
   - Summary Faithfulness must be $\ge 70.0\%$
   Any prompt or model change that causes a regression automatically blocks the pull request.
